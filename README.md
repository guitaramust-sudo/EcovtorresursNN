
# Эковторресурс — Корпоративный сайт

Корпоративный лендинг для компании ООО «Эковторресурс», специализирующейся на переработке и экологических решениях.

## Ссылка на проект
Проект задеплоен и доступен по адресу:  
[https://guitaramust-sudo.github.io/EcovtorresursNN/](https://guitaramust-sudo.github.io/EcovtorresursNN/)

## Стек технологий
* **Frontend:** React 18+, TypeScript
* **Styling:** Pure CSS (кастомная реализация слайдеров и навигации)
* **Assets:** SVG, Lazy-loading для изображений

## Особенности реализации
* **Custom Slider:** Самописный слайдер, реализованный на Flexbox и React Hooks (`useRef`). Отсутствие сторонних библиотек минимизирует вес сборки.
* **Responsive Design:** Полная адаптивность под любые разрешения экранов. Применены современные CSS-функции (`clamp`, `calc`) для динамического изменения размеров элементов.
* **Fixed Navigation:** Хедер с логикой изменения стилей при скролле и корректной обработкой якорных ссылок через `scroll-margin-top`.
* **Performance:** Высокие показатели в Lighthouse за счет оптимизации медиа-контента и отсутствия тяжелых зависимостей.

## Запуск проекта
Проект настроен для автоматического деплоя через GitHub Actions на GitHub Pages.

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/guitaramust-sudo/EcovtorresursNN.git
   ```
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Локальный запуск:
   ```bash
   npm run dev
   ```
